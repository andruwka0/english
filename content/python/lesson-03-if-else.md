# Условия `if` и `else`

Программа умеет не только выполнять команды по порядку, но и выбирать действие.
Для этого нужны условия.

## Считаем с числами

```python
first = 8
second = 2

print(first + second)  # сложение: 10
print(first - second)  # вычитание: 6
print(first * second)  # умножение: 16
print(first / second)  # обычное деление: 4.0
```

Обычное деление через `/` может дать число с точкой: `5 / 2` равно `2.5`.

## Сравниваем значения

Сравнение отвечает на вопрос и возвращает `True` или `False`.

```python
print(9 > 4)   # True: 9 больше 4
print(2 < 7)   # True: 2 меньше 7
print(5 == 5)  # True: значения равны
print(5 == 3)  # False
```

Один знак `=` записывает значение в переменную. Два знака `==` сравнивают значения.

## `if` и `else`

После `if` программа проверяет условие. Если оно `True`, выполняется блок с отступом.
Если условие `False`, выполняется блок `else`.

```python
age = 10

if age > 9:
    print("Можно смотреть фильм")
else:
    print("Пока выберем другой фильм")
```

Отступ в четыре пробела обязателен: он показывает, какие команды относятся к условию.

## Запомни

- `+`, `-`, `*`, `/` помогают считать;
- `>`, `<`, `==` сравнивают;
- `if` выполняет код при `True`;
- `else` выполняет код во всех остальных случаях.
