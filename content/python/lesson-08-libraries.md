# Библиотеки и `random`

Библиотека - это готовый набор полезных инструментов. Сначала ее нужно подключить.

```python
import random

print(random.randint(1, 6))
```

`random.randint(1, 6)` выбирает случайное число от 1 до 6 включительно.
`random.choice(items)` выбирает один случайный элемент из списка.
