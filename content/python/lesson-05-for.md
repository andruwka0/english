# Цикл `for` и `range()`

Цикл помогает повторять действие много раз без одинаковых строк кода.

```python
for number in range(1, 6):
    print(number)
```

`range(1, 6)` начинает с 1 и останавливается перед 6. Третий аргумент задает шаг:

```python
for number in range(2, 11, 2):
    print(number)
```

Так будут напечатаны четные числа от 2 до 10.
