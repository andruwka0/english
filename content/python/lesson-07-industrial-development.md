# Урок 7. Знакомство с промышленной разработкой

> **Цель:** узнать, как программисты пишут большие программы и какими инструментами пользуются каждый день.

## От браузерного редактора к проекту

В учебной платформе код запускается прямо в браузере. Это удобно для первых шагов. Но настоящие программы состоят из многих файлов, используют библиотеки и развиваются со временем. Для этого нужна среда разработки - IDE или редактор кода.

## Что такое IDE

IDE (*Integrated Development Environment*) - программа, в которой удобно писать, запускать и проверять код. Она подсвечивает ошибки, помогает открывать файлы проекта и пользоваться терминалом.

### PyCharm

[PyCharm Community Edition](https://www.jetbrains.com/pycharm/download/) - среда разработки от JetBrains. Она особенно удобна для Python: создаёт проекты, подсказывает код и помогает находить ошибки.

### Visual Studio Code

[Visual Studio Code](https://code.visualstudio.com/) - лёгкий редактор. После установки расширения Python в нём удобно писать не только Python, но и сайты, JavaScript и другие языки.

## Как начать

1. Установи Python с [официального сайта](https://www.python.org/downloads/).
2. Установи PyCharm или VS Code.
3. Создай папку `my-python-project`.
4. Создай в ней файл `main.py`.
5. Напиши и запусти первую программу:

```python
print("Привет из моего проекта!")
```

## Файлы и проекты

Проект - это папка со всеми файлами программы. Файл `main.py` часто становится точкой входа. Позже появятся отдельные файлы для игр, функций, настроек и данных.

## Терминал

Терминал - место, где компьютеру дают текстовые команды. Python-файл часто запускают так:

```text
python main.py
```

Сначала это кажется необычным, но терминал - просто ещё один полезный инструмент.

## Как работают разработчики

- делят большую задачу на маленькие шаги;
- дают файлам и переменным понятные имена;
- запускают программу после небольших изменений;
- читают ошибки и исправляют их по одной;
- сохраняют историю проекта в Git.

Ты уже пишешь настоящие программы. IDE просто даёт для этого удобный рабочий стол. На этом модуль заканчивается, но дальше Python сможет привести тебя к играм, сайтам, ботам и анализу данных.
