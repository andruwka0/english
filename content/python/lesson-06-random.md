# Урок 6. Библиотеки и `random`

> **Цель:** понять, что такое библиотеки, и добавить случайность в программу с помощью `random`.

## Что такое библиотека

Python умеет многое сам, но полезные инструменты собраны в отдельных библиотеках. Библиотека - это готовый код, который можно подключить к своему проекту.

```python
import random
```

После этой строки становятся доступны инструменты модуля `random`.

## `randint()` - случайное целое число

```python
import random

number = random.randint(1, 6)
print(number)
```

`randint(1, 6)` возвращает случайное целое число от 1 до 6 включительно. Это похоже на бросок кубика.

## `choice()` - случайный выбор

```python
import random

colors = ["красный", "синий", "зелёный"]
color = random.choice(colors)
print(color)
```

`choice()` выбирает один случайный элемент из списка или строки.

## `shuffle()` - перемешивание

```python
import random

cards = ["туз", "король", "дама"]
random.shuffle(cards)
print(cards)
```

`shuffle()` меняет порядок элементов в самом списке и ничего не возвращает. Поэтому не нужно писать `cards = random.shuffle(cards)`.

## Где пригодится случайность

- бросок кубика;
- случайный противник в игре;
- вопрос в викторине;
- перемешивание карточек;
- генератор идей для рисунка или истории.

## Частые ошибки

1. Забыть `import random`.
2. После `import random` написать `randint()` без `random.`.
3. Ждать новый список от `shuffle()`.
4. Забыть, что `randint` включает обе границы.

## Шпаргалка

```python
import random

random.randint(1, 10)
random.choice(["да", "нет"])
random.shuffle(items)
```

Библиотеки позволяют собирать интересные программы из готовых инструментов.
