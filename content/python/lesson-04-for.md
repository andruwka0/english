# Урок 4. Цикл `for` и `range()`

> **Цель:** научиться повторять действия без копирования одинакового кода.

## Что такое цикл

Цикл повторяет код. Вместо пяти одинаковых `print()` можно написать одну понятную конструкцию.

```python
for number in range(5):
    print(number)
```

Переменная `number` получает следующее значение на каждом шаге. Этот пример выведет числа от 0 до 4.

## `range()`

`range()` создаёт последовательность чисел.

| Запись | Результат |
| --- | --- |
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |

Правая граница не включается. Третий аргумент - шаг.

```python
for number in range(1, 6):
    print(number)
```

## Цикл по строке

Строка состоит из символов, поэтому по ней тоже можно пройтись.

```python
word = "кот"
for letter in word:
    print(letter)
```

## Накопитель

Цикл часто используют для суммы.

```python
total = 0
for number in range(1, 6):
    total = total + number

print(total)
```

`total` - накопитель: на каждом шаге он хранит уже найденную часть ответа.

## `if` внутри `for`

Условие можно проверять на каждом шаге цикла.

```python
for number in range(1, 11):
    if number % 2 == 0:
        print(number)
```

На каждом шаге условие даёт `True` или `False`. Поэтому программа печатает только чётные числа.

## Частые ошибки

1. Забыть двоеточие после `for`.
2. Забыть отступ в теле цикла.
3. Ждать, что `range(1, 5)` включает 5.
4. Сбрасывать накопитель внутри цикла.

```python
for item in последовательность:
    # повторяющийся код
```
