# Несколько вариантов: `elif`

Иногда двух вариантов недостаточно. `elif` означает «иначе, если» и добавляет еще одну проверку.

```python
score = 7

if score >= 9:
    print("Отлично")
elif score >= 5:
    print("Хорошо")
else:
    print("Потренируемся еще")
```

Программа читает условия сверху вниз и останавливается на первом подходящем варианте.

## Новые сравнения

`>=` значит «больше или равно», а `<=` значит «меньше или равно».

```python
print(10 >= 10)  # True
print(3 <= 8)    # True
```

Используй `if`, `elif` и `else`, когда у программы больше двух разных ответов.
