# Урок 3. Условия: `if`, `elif`, `else`

> **Цель:** научиться выбирать разные действия программы в зависимости от условия.

## Зачем нужны условия

Программа не всегда должна делать одно и то же. Ей может понадобиться определить, чётное ли число, можно ли пройти дальше или какую оценку показать. Для этого Python проверяет условие и выбирает ветку.

```python
age = 12

if age >= 12:
    print("Можно смотреть фильм")
```

После условия всегда ставится двоеточие, а код внутри ветки пишется с отступом в четыре пробела.

## `True` и `False`

Любое условие даёт один из двух ответов: `True` - правда, или `False` - неправда.

```python
print(5 > 3)   # True
print(5 == 3)  # False
```

Не путай `=` и `==`: один знак записывает значение, два - сравнивают.

| Оператор | Значение | Пример |
| --- | --- | --- |
| `==` | равно | `age == 12` |
| `!=` | не равно | `name != "Иван"` |
| `>` / `<` | больше / меньше | `score > 10` |
| `>=` / `<=` | больше или равно / меньше или равно | `age >= 18` |

## `if` и `else`

`if` выполняет код при `True`, а `else` - во всех остальных случаях.

```python
number = 7

if number % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

`%` показывает остаток от деления. У чётного числа остаток от деления на 2 равен 0.

## Несколько вариантов: `elif`

Когда вариантов больше двух, между `if` и `else` используют `elif` - «иначе если».

```python
score = 8

if score >= 9:
    print("Отлично")
elif score >= 6:
    print("Хорошо")
else:
    print("Нужно ещё потренироваться")
```

Python идёт сверху вниз и выполняет первую подходящую ветку. Поэтому более строгие условия пишут выше.

## Логические операторы

```python
age = 12
has_ticket = True

if age >= 10 and has_ticket:
    print("Можно проходить")
```

- `and`: истинны оба условия;
- `or`: истинно хотя бы одно условие;
- `not`: меняет ответ на противоположный.

```python
is_raining = False
if not is_raining:
    print("Можно гулять")
```

## Частые ошибки

1. Забыть двоеточие после `if`.
2. Забыть отступ внутри ветки.
3. Написать `=` вместо `==`.
4. Поставить широкую проверку выше узкой.

## Шпаргалка

```python
if условие:
    # код при True
elif другое_условие:
    # ещё один вариант
else:
    # всё остальное
```
