# Списки

Список хранит несколько значений в одной переменной.

```python
fruits = ["яблоко", "груша", "банан"]
print(fruits[0])
print(len(fruits))
```

Первый элемент имеет номер `0`. Функция `len()` показывает длину списка.

Можно добавлять элементы:

```python
fruits.append("слива")
```

По списку удобно проходить циклом `for`.

```python
for fruit in fruits:
    print(fruit)
```
