# Урок 5. Цикл `while`

> **Цель:** повторять код, пока условие остаётся истинным.

## `while` и `for`

`for` удобен, когда есть готовая последовательность. `while` нужен, когда заранее неизвестно, сколько повторений потребуется.

```python
count = 1

while count <= 5:
    print(count)
    count = count + 1
```

Пока `count <= 5` даёт `True`, тело цикла повторяется.

## Условие остановки

Внутри `while` обычно нужно менять переменную, от которой зависит условие.

```python
energy = 3

while energy > 0:
    print("Играем!")
    energy = energy - 1

print("Пора отдыхать")
```

Когда `energy` станет 0, условие вернёт `False` и цикл закончится.

## Бесконечный цикл

```python
count = 1
while count <= 5:
    print(count)
```

Это бесконечный цикл: `count` не меняется. Перед запуском всегда спрашивай: «Когда условие станет `False`?»

## Сумма с помощью `while`

```python
number = 1
total = 0

while number <= 5:
    total = total + number
    number = number + 1

print(total)
```

`number` - счётчик, `total` - накопитель.

## Когда пригодится `while`

- пока не закончились попытки;
- пока пользователь не дал правильный ответ;
- пока у героя есть энергия;
- пока выполняется условие.

```python
while условие:
    # повторяющийся код
    # меняем условие, чтобы цикл мог закончиться
```
